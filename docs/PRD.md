# tamago PRD

Oct 11, 2026 · @Emily

## 产品概述

tamago 是一个以"守护蛋"为世界观的送礼灵感与提醒工具：记录朋友和家人的生日、喜好和送礼历史，并用 AI 孵化贴合个人的新礼物灵感。

**背景与痛点**

- 记不住："去年送过什么来着？""她最近喜欢什么？"，信息散落在聊天记录和购物订单里
- 顾虑多：担心对方是否喜欢、礼物是否合适、价位怎么定，准备一份礼物要花大量时间和精力
- 同质化：在购物平台搜"生日礼物"，结果大多千篇一律，缺少和送礼对象相关的个人属性

**产品目标**

1. 缩短准备一份礼物的时间：从翻聊天记录、刷购物软件，变成打开一个朋友的蛋就能看到全部信息和灵感
2. 让推荐有个人属性：基于喜好标签、送礼历史和预算生成建议，并避开送过的东西
3. 让送礼有仪式感：每个朋友是一颗守护蛋，礼物墙记录你们之间的交集与羁绊

**设计灵感**：来自童年动画中"守护蛋"的概念。"我"通过送礼来守护朋友们的心灵之蛋。所有角色、蛋的图案和视觉元素均为原创设计，不使用原作的角色、名称或图案。

## 目标用户与使用场景

第一版的目标用户是"我自己"：一个重视仪式感、朋友圈里有不少需要送礼对象的年轻人。产品以个人使用为前提设计，同时作为公开网页发布，任何人打开链接都能独立使用。

**主要场景**

- 朋友生日快到了，想知道还有几天、去年送过什么
- 没有灵感，希望根据对方最近的喜好和预算得到几个有理由的方案
- 送完礼物后，想把它记录下来，留作以后的参考和回忆
- 平时聊天中得知朋友的新喜好（比如最近迷上芭蕾风），随手记成标签

**平台**：手机优先的网页，支持"添加到主屏幕"，以接近 app 的形式使用；电脑端同样可用。选择网页而非原生 app，是为了在有限时间内验证想法，并让任何人都能通过链接直接体验。

## 用户旅程

**首次使用**

1. 打开网页，看到欢迎界面，介绍 tamago 和守护蛋的概念
2. 选择"登记第一颗守护蛋"，或"载入示例"先体验
3. 填写朋友/家人信息：名字、分类、生日、喜好标签、最近一次送的礼物
4. 选择这颗蛋的颜色，完成登记，进入首页

**日常使用**

1. 打开首页，看到自定义时间区间内（默认 30 天）即将过生日的人和"还有 X 天"
2. 进入目录，按朋友/家人分类浏览所有守护蛋
3. 点开一颗蛋，查看个人信息、喜好标签和礼物墙
4. 点击"Start"进入 AI 灵感孵化，先选择预算区间和场合
5. AI 生成 Plan A 和 Plan B 及推荐理由；如果和送过的礼物同品类，会给出提醒
6. 点击"我更喜欢这个！"选出偏好方案
7. 确定礼物后，一键登记到礼物墙，可补充照片

## 页面说明

共 5 个页面加 2 个弹窗，布局参考手绘草图。

**1. 欢迎页**（仅首次打开）

- 产品名 tamago、一句话介绍、一颗原创守护蛋插画
- 主按钮"登记第一颗守护蛋"，次按钮"载入示例"

**2. 首页**

- 中央大蛋：最近一位过生日的人，显示"In X Days"和"Mary's 26th Birthday"
- 大蛋下方：时间区间内其他即将到来的生日，小蛋横排展示
- 区间内无人过生日时：显示空状态文案，并引导去目录添加

**3. 目录（朋友/家人一览）**

- Friends 和 Family 两个分区，每人一颗带名字的蛋
- 每个分区末尾有"+"添加按钮；人数多时分页显示

**4. 详情页**

- 头部：名字（年龄）、蛋、生日、星座
- Personal color：几个代表色圆点，可编辑
- Tags：喜好标签，可随时增删
- Gift Wall：礼物以圆形照片展示，末尾"+"手动添加；点开查看礼物详情
- 纪念日与认识年数（P1）
- Idea Incubator：说明文字和"Start"按钮

**5. AI 灵感孵化页**

- 第一步：选择预算区间和场合
- 第二步：孵化动画后展示 Plan A 和 Plan B，每个方案包含礼物、大致价位和推荐理由
- 同品类提醒：以提示条展示，附上礼物墙中相关礼物的图片
- 每个方案下有"我更喜欢这个！"按钮，以及"就送这个"按钮（登记到礼物墙）
- 都不满意时可"重新孵化"

**弹窗**

- 添加/编辑朋友：名字、分类、生日、蛋的颜色、标签、最近一次送的礼物
- 添加/编辑礼物：名称、品类、日期、场合、照片、对方反应

**导航**：手机端使用底部导航栏（首页、目录、设置），电脑端可保留侧边栏。设置页放导出/导入备份和时间区间设置。

## AI 灵感孵化逻辑

AI 的作用是把散落的个人信息整合成两个有理由、不重复的礼物方案，而不是给出一个通用礼物清单。

**输入（自动整理后发给 AI）**

- 基本信息：年龄、星座、和我的关系
- 喜好标签和 Personal color
- 礼物墙：历年礼物的名称、品类、对方反应（只发送文字，不发送照片）
- 本次选择：预算区间、场合
- 偏好记录：过去在 Plan A/B 中选择了哪个、选中方案的特点

**输出（固定格式，便于页面展示）**

- Plan A 和 Plan B，两个方案方向要有差异（例如一个实用、一个有纪念意义）
- 每个方案：礼物名称、品类、大致价位、推荐理由（引用具体的喜好标签）
- 同品类标记：如与礼物墙中已有礼物同品类，标出是哪几件

**偏好学习**

用户点击"我更喜欢这个！"后，记录被选中和未被选中的方案。下一次孵化时，把最近几次的选择作为参考写入提示词，例如"用户更偏好有纪念意义的礼物"。这里的"学习"不是训练模型，而是通过积累上下文让推荐越来越贴合。

**同品类提醒**

由于礼物墙的存在，AI 不会推荐完全相同的礼物，但可能推荐同一品类（例如之前送过包，又推荐另一个包）。此时页面显示提示，例如"你之前送过 Mary 这些包包"，并附上礼物墙中对应礼物的照片，由用户自己判断是否合适。品类判断由 AI 根据文字完成，照片由页面从本地数据中调出。

**出错处理**

- 生成失败或超时：显示友好提示和"重新孵化"按钮，不丢失已选的预算和场合
- 返回格式不对：页面尝试重新请求一次，仍失败则提示重试
- 信息太少（例如没有任何标签）：孵化前提示"多添加几个喜好标签，灵感会更准哦"，但仍允许继续

## 数据与隐私

所有数据只保存在用户自己的浏览器里，不需要注册登录，也不上传到服务器。

- **本地存储**：朋友信息、礼物墙、偏好记录存在浏览器本地；不同用户打开同一链接，数据互不可见
- **发送给 AI 的内容**：仅在点击孵化时，发送该朋友的文字信息用于生成灵感，不发送照片
- **照片压缩**：浏览器本地存储空间有限（通常只有几 MB），上传的礼物照片需先压缩成小图
- **导出/导入备份**：在设置页一键导出包含全部数据和照片的备份文件；换设备或清除缓存后可导入恢复
- **风险提示**：在设置页说明"清除浏览器数据会删除记录，请定期备份"

## 设计风格

整体风格是简洁、可爱、梦幻：奶白底色、温暖的 pastel 色调、圆润字体和大圆角。

| 元素 | 规范 |
| --- | --- |
| 关键词 | 守护蛋世界观、简洁、可爱、梦幻 |
| 主色 | 奶白色（背景） |
| 辅助色 | baby blue、pastel pink、cream yellow |
| 文字色 | 深色（如深灰或深蓝），保证在浅色背景上清晰可读 |
| 字体 | 圆润字体，中文可选站酷快乐体或圆体，英文可选 Nunito 或 M PLUS Rounded |
| 圆角 | 卡片和按钮使用大圆角 |

**守护蛋**

- 所有蛋使用统一的原创造型，第一版只开放自选颜色
- 生日临近时，蛋上逐渐出现裂纹（P1）
- "孵化灵感"时可配一段简单的蛋晃动或发光动画，增强仪式感

**原创性**：灵感来自守护蛋的概念，但蛋的图案、配色和插画均为原创，不使用原作角色、名称、经典蛋纹样或标志。

## 异常与边界情况

| 情况 | 处理方式 |
| --- | --- |
| 首页时间区间内无人过生日 | 显示空状态文案，并显示下一个最近的生日 |
| 多人同一天过生日 | 首页大蛋左右滑动切换 |
| 2 月 29 日出生 | 非闰年按 2 月 28 日提醒 |
| 只知道月日、不知道出生年份 | 年份可留空，此时不显示年龄 |
| 朋友没有任何标签 | 孵化前提示补充标签，但允许继续 |
| 照片过大 | 自动压缩；超出存储空间时提示导出备份 |
| 删除朋友 | 二次确认，提示礼物墙记录会一起删除 |
| 导入的备份文件格式错误 | 提示文件无法识别，不覆盖现有数据 |
| AI 生成失败或超时 | 提示并提供"重新孵化"按钮 |
| 小屏手机 | 所有页面按手机宽度设计，不出现横向滚动 |

## 成功指标、后续规划与待定问题

**成功指标（第一版自测）**

- 准备一份礼物的时间：记录使用前后的对比，例如从约 2 小时缩短到 15 分钟
- 推荐采纳率：孵化出的方案中，最终登记到礼物墙的比例
- 同品类提醒是否准确：手动检查 10 次孵化结果
- 新用户能否在 2 分钟内完成第一颗蛋的登记

**后续规划**

- 共同好友协作：为某人的生日生成共享"礼物认领"链接，避免送重（需要多人共享数据）
- 导出到日历，由手机日历负责推送提醒
- 自定义蛋的图案、礼物购买链接
- 孵化完成后，蛋"孵化"出一个小图标放进礼物墙，让仪式感更完整

**待定问题**

- [ ] AI 接入方式：个人使用，API 密钥由用户在设置页填写，只存在浏览器本地
- [ ] 预算区间的档位怎么划分（例如 200 以下、200–500、500–1000、1000 以上）：滑动游尺，可自定义价格区间
- [ ] 礼物照片是否为必填：否
- [ ] 详情页是否需要"和我的关系"字段（如大学室友、同事）：否
- [ ] 偏好记录参考最近几次选择

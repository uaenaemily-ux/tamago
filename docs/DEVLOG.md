## 第 0 步：规划与文档（2026-10-11）
- **问题**：PRD 文件名异常，显示为 `~:Projects:tamago:docs:PRD.md`
- **原因**：保存时把完整路径当成了文件名（macOS 中路径里的 `/` 会显示为 `:`）
- **解决**：重命名为 `docs/PRD.md`

## 第 1 步：页面骨架 + 字体（2026-10-11）
- **字体选择**：正文用系统自带的苹方（非苹果设备依次退回微软雅黑、思源黑体/Noto Sans CJK、文泉驿）；标题、数字、按钮用「秋叶圆体 16」截取后的 Tamago Title
  - 原因：对比站酷快乐体、M PLUS Rounded 1c、系统字体后，由用户选定（选择秋叶圆体的具体理由待补充）；正文用系统字体，不用下载、显示最稳定
- **问题**：秋叶圆体完整字体 3.3 MB，网页加载太慢
  - **原因**：中文字体包含上万个字
  - **解决**：用 `tools/subset-font.py` 只截取网页文案里用到的字，输出 `fonts/tamago-title.woff2`，约 10 KB
- **问题**：字体能不能用在网页上
  - **原因**：fonts/ 里没有授权文件，需要到原作者仓库核实
  - **解决**：字体使用 SIL OFL 1.1，可以免费用于网页；作者在 README 声明保留名称「秋叶圆体 16」「QiuYeYuanTi 16」，截取属于修改，所以截取版改名为 "Tamago Title"，保留原版权信息，并附上 `fonts/OFL.txt`
- **问题**：用户输入的名字（比如中文朋友名）不在截取范围里
  - **原因**：截取只包含代码里写死的文案
  - **解决**：这些字会自动用正文字体（苹方）显示，暂时接受；如果效果不好，以后再考虑加入常用 3500 字
- **问题**：点阵字体在某些字号下会发糊
  - **原因**：秋叶圆体是 16px 点阵字体
  - **解决**：标题字号只用 16 的倍数（16 / 32 / 48px），并禁止浏览器自动加粗（font-synthesis: none）

## 第 1 步补充：美术风格（2026-10-11）
- **风格决定**：甜美梦幻为主，保留天使元素；背景用粉白斜格纹；卡片用白底 + 粉色虚线边框；装饰同时使用手绘线条和像素小图标
  - 原因：用户查看 design-refs/ 参考图的风格总结后选定；斜格纹参考 design-refs/background.png
- **问题**：参考图里有原作角色、经典蛋纹样和现成角色（如三丽鸥），不能直接使用
  - **原因**：版权和 PRD 的原创性要求
  - **解决**：所有装饰都重新原创绘制（手绘闪光、天使翅膀、像素爱心 / 星星 / 翅膀 / 导航图标）；design-refs/ 已加入 .gitignore，不提交
- **问题**：主按钮"粉底白字"对比度只有 1.9，手机上看不清；灰色说明文字对比度只有 4.25
  - **原因**：浅粉背景上的白字太淡；灰色不够深
  - **解决**：主按钮改为粉底深色字（6.3）；说明文字加深到 #7A6470（5.4）；小字号强调色新增 --color-pink-700（4.85）
- **问题**：第一版格纹是横竖方格，和想要的效果不一样
  - **原因**：一开始没有指定格纹方向
  - **解决**：改为两组 45° 斜条交叉的菱形格纹，颜色调到很淡
- **备注**：iPhone 的 Safari 不支持 background-attachment: fixed，格纹会跟着页面一起滚，不影响使用

## 第 2 步：数据层（2026-10-11）
- **结果**：tests/ 测试页 29 项全部通过
- **问题**：jsDelivr 上 idb-keyval 的授权文件下载失败（404）
  - **原因**：这个包的授权文件名是英式拼写 `LICENCE`，不是 `LICENSE`
  - **解决**：按正确的文件名下载，保存为 `js/vendor/idb-keyval.LICENSE`
- **问题**：加入数据层后，截取的标题字体从 10.8 KB 涨到 25 KB
  - **原因**：截取脚本把代码注释里的中文也算进去了
  - **解决**：JS 文件只收集字符串里的文字，HTML 跳过注释，字体降到 14.5 KB
- **问题**：用局域网地址（http）在手机上测试时，持久存储显示 unsupported
  - **原因**：浏览器只在 https 或 localhost 下提供持久存储
  - **解决**：属于正常现象，GitHub Pages 是 https，部署后可以正常申请；生成 id 也改用 crypto.getRandomValues，在 http 下同样能用
